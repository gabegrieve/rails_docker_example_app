# README

## What's in the repo

Dockerfile              # generated by Rails — production build (for Kamal/deploys)
Dockerfile.dev          # added — slim dev image used by docker-compose
docker-compose.yml      # added — web + db services
config/database.yml     # tweaked — reads DATABASE_HOST/USERNAME/PASSWORD from env
[everything else]       # vanilla `rails new --database=postgresql` output

The only deviation from a vanilla rails new is the three lines added to default: in config/database.yml — they fall back to localhost/postgres/"" so the file still works for non-Docker use.

## Daily commands

docker compose up              # start (foreground, logs visible)
docker compose up -d           # start (detached)
docker compose down            # stop
docker compose logs -f web     # tail web logs
docker compose exec web bash   # shell into the app container
docker compose exec web bin/rails console
docker compose exec web bin/rails test
docker compose exec web bin/rails db:migrate

After editing the Gemfile, run docker compose build web (gems are baked into the image; the bundle_cache volume just keeps them across rebuilds).
